# Nicolas Garcia — Portfólio

Site pessoal de **Nicolas Miguel Gomes Garcia**, estudante de Engenharia de Software e desenvolvedor de sistemas SaaS, automações e aplicações web/desktop.

## 🚀 Tecnologias
- HTML5 semântico
- CSS3 puro (glassmorphism, animações, responsivo)
- JavaScript vanilla

## 📂 Estrutura
```
├── index.html
├── styles.css
├── script.js
└── assets/img/perfil.jpg
```

## ▶️ Rodando localmente
Basta abrir o `index.html` no navegador, ou:
```bash
npx serve .
```

## 🌐 Deploy
Site estático — pode ser publicado diretamente na **Vercel**, **Netlify** ou **GitHub Pages**.
